# MuJoCo READY 验证记录

本记录对应 `model_64500`，使用包内 ONNX、GJC 精确机器人模型、部署侧 111 维观测实现和独立 raised-neutral READY 参考动作，连续运行 10 秒（500 个 50 Hz 控制周期），全程没有球命令。

## 结果

- 未跌倒，非有限观测/动作均为 0。
- pelvis 高度最终为 `1.0676 m`；最大站位漂移 `2.81 cm`，最终漂移 `1.71 cm`。
- base pitch 最终 `-1.38 deg`，torso pitch 最终 `-4.63 deg`。
- 左/右手腕最终高度分别为 `1.144 m`、`1.067 m`；球拍最终高度 `1.070 m`。
- 手臂位于球台平面范围内时，保守 AABB 最小垂直余量约 `3.90 cm`。
- raw action 最大绝对值 `4.454`，没有触发 raw-action 裁剪。

## 尚未通过的姿势一致性

该策略在 READY 中稳定，但没有准确复现独立的中立准备姿势：

- READY 全关节最终 RMS 误差 `0.378 rad`（约 `21.7 deg`）。
- 左/右手腕相对参考的最终位置误差分别为 `14.0 cm`、`15.2 cm`。
- 腰 yaw/roll/pitch 最终实测为 `-11.16/+4.71/-2.91 deg`；参考 READY 为 `0/0/+3 deg`。
- 腰 pitch 的 policy 目标最终为 `-20.27 deg`，而实测为 `-2.91 deg`，说明输出仍强烈要求向前弯腰。
- 左右脚最终相对地面的倾角分别为 `11.76 deg`、`16.34 deg`，没有保持参考动作要求的平脚。

因此本包的结论是：**MuJoCo 中无球 READY 动力学稳定，但中立准备姿势跟踪不合格，尚不应视为可直接上真机的安全认证策略。** 建议先在吊绳/支撑和低增益条件下复核，或继续针对 READY 腰部、脚底和手腕跟踪训练。

完整机器可读结果位于 `validation/ready_no_command_10s.json`。本次没有把旧 `model_53000` 的困难多球结果继承为 `model_64500` 的验证结论；包内 `scripts/run_hard_eval.sh` 仅作为后续独立复测入口。
