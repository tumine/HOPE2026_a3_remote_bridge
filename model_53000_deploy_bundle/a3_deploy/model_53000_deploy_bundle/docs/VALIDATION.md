# 验证记录

使用本包 ONNX、GJC 精确模型和更新后的桌面参数，完成了 12 球连续正反手困难边界交替测试：

- 12/12 MuJoCo 真实接触
- 12/12 过网
- 12/12 对方台面落点
- 0 次跌倒
- 0 个非有限动作
- `success_rate = 1.0`

测试区域刻意靠近正反手横向、前后和高度边界：正手 `x=0.38..0.40, y=-0.755..-0.735, z=1.10..1.18 m`；反手 `x=0.70..0.74, y=0.075..0.095, z=0.86..0.94 m`。飞行时间 `0.8..1.0 s`，策略 lead time `1.0 s`，启动 base 随机范围 `x ±0.03 m, y ±0.20 m`。

原始逐球数据在 `validation/hard_alternating_12_new_table_physics.json`。这证明该固定仿真条件下的可重复结果，不等价于实机安全认证，也没有验证首次命令 TTS=0.25 s。
